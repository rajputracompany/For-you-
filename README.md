# My Dear Diary

A small surprise website for Aditi. Blue sky, drifting clouds, a bunch of wildflowers, and a diary page that opens with one click.

## Run it
Open `index.html` in any browser. No install needed.

## Put it on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md`.
3. Go to Settings > Pages, choose the `main` branch and the root folder, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Make it yours
Edit the lines inside `<section class="page">` in `index.html` to change what the diary says.
